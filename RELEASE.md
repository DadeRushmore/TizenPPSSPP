# TizenPPSSPP 0.24.4 — public source edition

Publishes the curated source of the 16 November development freeze as a browsable Git repository, with original application placeholder artwork, retained notices, an exact SHA-256 inventory and a repeatable publication check.

This is a **source-only development prerelease**, not an installer or a new TV-tested build. Native executables and selected prebuilt runtime assets are excluded. The binary-release work is listed in DISTRIBUTION.md. The private frozen packages are not part of this release.

Download the source ZIP and SHA256SUMS.txt attached to this release, or clone the repository. The source layout is documented in README.md and BUILD.md.
